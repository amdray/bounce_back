## Рекомендации по оптимизации

### 1. Формат текстур

- ✅ **RGB565** (2 bpp) для всего без alpha
- ✅ **RGBA4444** (2 bpp) для спрайтов с прозрачностью
- ❌ RGBA32 только где критична точность цвета (вряд ли нужно)

**Экономия:** 50% памяти на текстуры

### 2. Swizzled текстуры

- PSP поддерживает swizzled layout для улучшения cache coherency
- Особенно важно для больших текстур (фоны, заставки)
- **Ускорение:** 30-40% при рендеринге

### 3. VRAM allocation

- Храним часто используемые текстуры в VRAM (2 MB)
- Tileset + мяч + UI = ~110 KB в VRAM
- Остальное (меню, заставки) в обычной RAM

### 4. Динамическая загрузка

```
Старт игры:
  ├─ Загрузить меню (im) ~97 KB
  └─ Показать главный экран

Начало игры:
  ├─ Выгрузить меню
  ├─ Загрузить tileset темы
  ├─ Загрузить уровень
  └─ Старт

Память во время игры: ~200 KB
```

### 5. Загрузка тем

Загружать только **if0 + (if1 ИЛИ if2)**, а не все три:

- Без темы: if0 = 104 KB
- С темой 1: if0 + if1 = 111 KB
- С темой 2: if0 + if2 = 112 KB

**Не загружать:** if1 + if2 одновременно (экономия 7-8 KB)

## Выводы

### ✅ Основной вывод

**Все ресурсы игры занимают менее 1% памяти PSP даже без оптимизаций.**

Проект **очень компактный**, проблем с памятью не будет.

### 📊 Сравнение с другими PSP играми

Для справки, типичные PSP игры используют:

- **Puzzle игры:** 5-15 MB
- **2D платформеры:** 10-30 MB
- **3D игры:** 20-24 MB (почти вся доступная память)

**Bounce Back:** ~0.2-0.6 MB (в 30-100 раз меньше!)

### 🎯 Стратегия разработки

1. **Начать можно без оптимизаций** — используйте RGBA32, просто и работает
2. **Оптимизировать перед релизом** — RGB565 даст 50% экономии
3. **VRAM не критично** — даже без него все быстро работает
4. **Динамическая загрузка опциональна** — но упростит код (меню отдельно от игры)

### 🚀 Первые шаги (из BRING_UP.md)

Ваш изначальный план **правильный:**

1. **ResourceContainer (c.java)** — загрузчик контейнеров
2. **Тест "мяч на экране"** — загрузить `/res/b[0]` → SDL_Texture
3. **Tileset и уровень** — загрузить `/res/tf`, `/res/lf`, `/res/if0`
4. **Статичная отрисовка** — показать один уровень без gameplay

**Память не будет проблемой, фокус на корректность формата данных!**
